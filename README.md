# Linux Health Care

++A bash script that displays Linux system information and saves a timestamped report.++

## Checks
-Hostname and date
-System uptime
-Disk and memory usage
-Failed systemd services
-SSH service status
 
## Usage
```bash 
bash health-check.sh
 ```

(The report is saved in the current directory.) 

##Requirements
Linux with Bash, systemd, and standard GNU/Linux utilities

## Knowledge Gained
Grouping Bash commands, checking system information, and using pipes and teeto display and save outputs.
